# ProjeEkibiOneriSistemi



📌 Proje Açıklaması
Bu proje, veri odaklı analiz ile öğrenci profillerini değerlendirerek, dinamik ve optimum proje ekibi önerileri sunan bir sistemdir.
ASP.NET API kullanılarak geliştirilmiştir.
